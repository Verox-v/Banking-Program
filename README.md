Banking Program

A simple command-line banking application written in Python.

Features

Check current account balance

Deposit money

Withdraw money

Prevent deposits and withdrawals of zero or negative amounts

Prevent withdrawals that exceed the available balance

Display balance and transaction amounts to two decimal places

Technologies

Python 3

How to Run

Make sure Python 3 is installed.

Download or clone this repository.

Open the project folder in a terminal.

Run:

python main.py

Project Structure

banking-program/
├── main.py
